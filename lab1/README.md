# Лабораторная работа № 1

- **Автор:** Шикалова Вероника.
- **Группа:** ИУ9-51Б.
- **Вариант:** 3.
- **Тема:** восстановление системы переписывания термов по двойной кодировке.

## Задание

Восстановить систему переписывания скобочных термов и две ступени её кодирования по заданным цифровым строкам. Вариант содержит семь конструкторов, включая константы; система должна быть завершима.

Источники: [общая постановка](https://github.com/TonitaN/FormalLanguageTheory/issues/48), [условия вариантов](https://github.com/TonitaN/FormalLanguageTheory/blob/main/Лабораторная1_LLM.md).

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки не нужны. Из корня репозитория выполните:

```shell
python lab1/recover.py
python lab1/verify_solution.py
```

`recover.py` вычисляет коды из исходных строк в рамках выбранной модели постфиксной записи и форм левых частей. Правые части третьего и четвёртого правил получаются декодированием. Полнота поиска среди всех возможных кодировок не утверждается.

`verify_solution.py` проверяет явно заданный результат отдельно от поиска. Численная проверка весов служит контролем арифметики; общее доказательство завершимости приведено в [отчёте](solution.md#8-завершимость).
