## Инструкция

1. Прочитать [solution.md](solution.md): условие → выбор модели записи →
   перебор границ → разбор деревьев → проверка → доказательство завершимости.
2. Запустить `python recover.py`. Он действительно вычисляет цифровые коды
   из строк, а не читает готовый словарь. Печатает три допустимых словаря.
3. Запустить `python verify_solution.py`. Это отдельная проверка одного
   явно записанного решения: все восемь строк, обратное декодирование,
   сигнатура и условия на переменные.

Нужен Python 3.10+, внешних библиотек нет
