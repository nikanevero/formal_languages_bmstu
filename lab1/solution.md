# Лабораторная работа 1 (вариант 3)
Студента группы ИУ9-51Б Шикаловой Вероники

## 1. Условие

Даны закодированные правила переписывания:

```text
20022102 = 21112
311211022102 = 20102
3123212011122102 = 31221023212102201112
3123212011022102 = 31221023212011023123212102201102201112
```

Требуется восстановить систему скобочных термов и две ступени кодирования: термы переводятся в строки, затем символы строк заменяются цифровыми кодами. Обе ступени должны быть однозначны. В варианте семь конструкторов, включая константы, система завершима. По общему условию присутствуют переменные, арности конструкторов не превосходят трёх.

Построим расшифровку, удовлетворяющую этим требованиям. Обозначения конструкторов — заглавные буквы, переменных правил — строчные.

## 2. Выбор модели записи

Все левые части заканчиваются на `22102`. Рассмотрим постфиксную запись: сначала записываются аргументы, затем символ операции. В такой записи общий конец может содержать код общего внешнего конструктора F. При этом его код может быть короче `22102`, поскольку начало общего конца может принадлежать предыдущему символу.

Третья и четвёртая левые части имеют одинаковую длину и отличаются одной цифрой. В качестве простой модели рассмотрим одинаковые аргументы x, y, разные бинарные конструкторы H, J и общий внешний унарный конструктор F:

```text
F(H(x,y))    постфиксно: x y H F
F(J(x,y))    постфиксно: x y J F
```

Это выбор класса разборов для поиска, а не единственное следствие из сходства строк. Дополнительно потребуем суффиксной свободы кодов: никакой код не должен быть суффиксом другого. Это достаточное условие однозначного декодирования справа налево. Сначала ищем правые части третьего и четвёртого правил в алфавите символов соответствующих левых частей. Их форму в виде термов заранее не задаём.

## 3. Выделение кодов по третьему правилу

Левую строку `3123212011122102` разбиваем на четыре непустых блока, соответствующих x, y, H, F. В строке 16 цифр, поэтому возможны `C(15,3) = 455` вариантов положения трёх границ.

Для каждого разбиения выполняем две проверки:

1. Четыре полученных кода образуют суффиксно-свободный словарь.
2. Правая строка `31221023212102201112` декодируется этим словарём в один корректный постфиксный терм при арностях x:0, y:0, H:2, F:1.

Вторая проверка не требует определённой последовательности символов. Сначала снимаем цифровые коды с конца строки. Затем читаем полученную последовательность в обычном порядке стеком: лист кладём в стек, операция забирает свои аргументы и кладёт построенный терм. Нехватка аргументов или несколько термов в конце означают некорректный разбор.

Обе проверки проходит одно разбиение:

```text
312 | 321 | 201112 | 2102
 x     y       H       F
```

С найденными кодами правая часть разбирается следующим образом:

```text
312 | 2102 | 321 | 2102 | 201112
 x      F     y      F        H
```

Следовательно, третье правило имеет вид:

```text
F(H(x,y)) -> H(F(x),F(y))
```

Перебор и проверку реализует `rule3_splits` в `recover.py`.

## 4. Разбор четвёртого правила

Четвёртая левая часть начинается с найденных кодов x, y и заканчивается кодом F. Оставшийся средний блок определяет код J:

```text
312 | 321 | 201102 | 2102
 x     y       J       F
```

Добавляем `J = 201102` в словарь. Суффиксная свобода сохраняется. Декодируем правую строку тем же способом, без предполагаемой формы дерева:

```text
312 | 2102 | 321 | 201102 | 312 | 321 | 2102 | 201102 | 201112
 x      F     y       J     x     y      F       J        H
```

Стековый разбор даёт дерево `H(J(F(x),y),J(x,F(y)))`. Получено правило:

```text
F(J(x,y)) -> H(J(F(x),y),J(x,F(y)))
```

Таким образом, структура обеих правых частей получена декодированием.

## 5. Дополнение словаря по первым двум правилам

Из первой левой части удаляем уже известный конечный код F. Остаётся `2002`. Выбираем для остатка один символ A, а для правой части `21112` — один символ B. Как самостоятельные термы они имеют арность 0:

```text
2002 | 2102 -> 21112
 A       F        B
```

Из второй левой части после удаления F остаётся `31121102`. Выбираем разбор остатка как `z G`: лист z и унарный конструктор G. Данный разбор остатка может быть найден, если увидеть намёк на содержательный смысл полученных на данный момент правил (сам смысл будет разобран в пункте 9), или же простым ручным перебором нескольких разумных вариантов. Правую часть `20102` представляем одним символом C арности 0. В этой модели первые два правила имеют вид:

```text
F(A)    -> B
F(G(z)) -> C
```

Выбор коротких разборов позволяет получить простые базовые правила. Он также должен пройти проверки кодировки и числа конструкторов: одно лишь удаление суффикса F не определяет эти разборы однозначно.

Перебираем все границы между непустыми кодами z и G в `31121102`. Суффиксная свобода полного словаря сохраняется в трёх случаях:

| Код z | Код G |
|---|---|
| `3` | `1121102` |
| `31` | `121102` |
| `311` | `21102` |

Выберем последний вариант, в котором все переменные имеют трёхзначные коды. Все три варианта допустимы; единственность словаря не требуется для проверки построенной расшифровки.

## 6. Система и проверка ограничений

Полученная сигнатура и коды:

| Символ | Арность | Код |
|---|---:|---|
| A | 0 | `2002` |
| B | 0 | `21112` |
| C | 0 | `20102` |
| F | 1 | `2102` |
| G | 1 | `21102` |
| H | 2 | `201112` |
| J | 2 | `201102` |
| z | переменная | `311` |
| x | переменная | `312` |
| y | переменная | `321` |

Правила:

```text
F(A)      -> B
F(G(z))   -> C
F(H(x,y)) -> H(F(x),F(y))
F(J(x,y)) -> H(J(F(x),y),J(x,F(y)))
```

Конструкторов ровно семь: A, B, C, F, G, H, J. Из них A, B, C — константы. Переменные правил x, y, z в число конструкторов не входят. Максимальная арность равна 2. Ни одна левая часть не является переменной; все переменные правых частей присутствуют в соответствующих левых частях.

Повторное кодирование даёт:

```text
2002 | 2102 = 21112
311 | 21102 | 2102 = 20102
312 | 321 | 201112 | 2102 = 312 | 2102 | 321 | 2102 | 201112
312 | 321 | 201102 | 2102 = 312 | 2102 | 321 | 201102 | 312 | 321 | 2102 | 201102 | 201112
```

После удаления разделителей получаются в точности исходные четыре пары. Программа `verify_solution.py` независимо проверяет эти равенства, обратное декодирование и ограничения на сигнатуру и переменные.

## 7. Однозначность двух ступеней кодирования

Первая ступень задаётся постфиксным обходом:

```text
P(f(t1,...,tn)) = P(t1)...P(tn)f
P(x) = x для переменной x
```

При фиксированных арностях стековый разбор однозначно восстанавливает терм. Следовательно, эта ступень инъективна.

На второй ступени каждый символ заменяется кодом из таблицы, после чего коды склеиваются. Для любых слов p, q выполняется `h(pq)=h(p)h(q)`, поэтому отображение является гомоморфизмом.

Выбранный словарь суффиксно-свободен. При чтении с конца строки подходящий код может быть только один: два разных подходящих кода были бы суффиксами один другого. Последовательно снимая коды, однозначно восстанавливаем слово. Поэтому вторая ступень инъективна на всех словах промежуточного алфавита. Вспомогательные символы для кодирования не используются.

## 8. Завершимость

Число узлов не является убывающей мерой: четвёртое правило увеличивает размер терма. Оно также увеличивает число F, но каждый F справа получает меньший аргумент. Учтём это полиномиальной интерпретацией на положительных целых числах:

```text
W(A) = W(B) = W(C) = 1
W(G(t)) = W(t) + 1
W(H(s,t)) = W(J(s,t)) = W(s) + W(t) + 1
W(F(t)) = W(t)^2 + 1
```

Квадрат даёт слагаемое `2ab` для объединённых аргументов слева, которого нет у отдельных применений F справа. Проверим, что этого достаточно для строгого уменьшения во всех правилах.

Назначим переменным произвольные положительные целые веса: `W(z)=c`, `W(x)=a`, `W(y)=b`. Разности весов левых и правых частей:

| Правило | Разность | Нижняя граница при a,b,c ≥ 1 |
|---|---|---:|
| F(A) | `1` | 1 |
| F(G(z)) | `(c+1)^2` | 4 |
| F(H(x,y)) | `2ab+2a+2b-1` | 5 |
| F(J(x,y)) | `2ab+a+b-3` | 1 |

Для третьего правила:

```text
(a+b+1)^2+1 - ((a^2+1)+(b^2+1)+1)
= 2ab+2a+2b-1 ≥ 5
```

Для четвёртого правила:

```text
(a+b+1)^2+1 - (((a^2+1)+b+1)+(a+(b^2+1)+1)+1)
= 2ab+a+b-3 ≥ 1
```

Каждое правило строго уменьшает вес при любых подстановках. Все функции интерпретации строго возрастают по каждому аргументу, поэтому уменьшение сохраняется и при переписывании внутри произвольного терма. Бесконечной строго убывающей последовательности положительных целых чисел нет. Следовательно, система завершима при любом выборе правил и позиций.

## 9. Содержательная интерпретация

В третьем правиле F применяется к каждому аргументу H. Четвёртое правило заменяет F от J двумя слагаемыми, в каждом из которых F применяется к одному из аргументов. Вместе с первыми двумя правилами это даёт интерпретацию как символьное дифференцирование:

| Символ | Смысл |
|---|---|
| F | Производная |
| H | Сложение |
| J | Умножение |
| A | Фиксированный символ переменной дифференцирования |
| B | Единица |
| C | Ноль |
| G(z) | Постоянный коэффициент с параметром z |

Для этой интерпретации z обозначает коэффициент, не зависящий от A. A является константой сигнатуры TRS, а x, y, z — переменными подстановки. Правил арифметического упрощения в системе нет. Доказанная завершимость не зависит от интерпретации и выполняется для всех термов данной TRS.

Таким образом, построена содержательная расшифровка, удовлетворяющая условиям варианта. Поиск ограничен выбранной моделью записи и левых частей; единственность расшифровки среди всех допустимых кодировок не утверждается.
